# 📁 Проект: FManager

### 🚀 Имитация файлового менеджера + DevOps автоматизация + Linux-администрирование + Мониторинг инфраструктуры

**Описание:**  
Учебный проект для практической отработки навыков DevOps и системного администрирования Linux. Представляет собой клиент-серверное приложение (frontend + backend), полностью контейнеризированное с помощью Docker Compose, автоматизированное через CI/CD конвейер и обвешанное промышленным стеком мониторинга.

---

## 🛠️ Технологический стек

* **Backend:** Python (FastAPI), Uvicorn
* **Frontend:** HTML5, JavaScript, Nginx
* **Automation & Admin:** Bash / Shell-скрипты, системный планировщик Cron, Systemd демоны
* **Containerization:** Docker, Docker Compose
* **Monitoring:** Prometheus Server, cAdvisor (метрики контейнеров), Node Exporter (метрики железа), Grafana Labs
* **CI/CD:** GitHub Actions (Линтинг + Автосборка + Smoke-тесты)

---

## 🚀 Быстрый запуск

Вы можете развернуть весь проект одной командой. Для этого склонируйте репозиторий и запустите Docker Compose:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd FManager
docker.compose up -d --build
```

## 📊 Инфраструктурный мониторинг

В проекте реализована гибридная схема сбора метрик (контейнеры + физическое "железо" хоста) в режиме `network_mode: host`:
1. **Node Exporter:** Установлен локально на операционную систему через `systemd`-демоны. Собирает данные о нагрузке CPU, RAM, состоянии SSD-дисков и сетевых интерфейсов ноутбука.
2. **cAdvisor:** Контейнерный шпион от Google, собирающий сырые метрики загрузки и лимитов всех запущенных Docker-контейнеров кластера.
3. **Prometheus:** Централизованная база данных временных рядов (TSDB), опрашивающая таргеты хоста и Докера раз в 15 секунд.
4. **Grafana:** Платформа визуализации. Импортированы профессиональные дашборды (ID `1860` для Node Exporter и ID `14282` для cAdvisor) для контроля за всей инфраструктурой из единого окна.

## ⚙️ Настроенный CI/CD Пайплайн

При каждом `push` или `pull_request` в ветку `main` автоматически запускается GitHub Actions workflow:
1. **Linting:** Проверка стиля и качества Python-кода backend на соответствие стандарту PEP8 с помощью утилиты `flake8`.
2. **Build:** Автоматическая тестовая сборка Docker-образов для frontend и backend (проверка синтаксиса Dockerfile).
3. **Smoke-тесты:** Запуск контейнеров в окружении GitHub Actions и проверка доступности портов (`curl`) для подтверждения успешного старта сервисов.

## 💾 Автономная Linux-часть (Локальные скрипты)

В папке `scripts/` развернута независимая система обслуживания сервера, работающая через `cron`:
* `backup` — ежечасное создание сжатых архивов (`tar.gz`) папки хранения файлов `uploads/`.
* `cleanMEM` — автоматическая ротация бэкапов (удаление архивов старше 7 дней через утилиту `find`).
* `status` — скрипт мониторинга занятого места файла проекта и общего состояния жесткого диска (`df / du`).
* `install_node.sh` & `install_prometheus.sh` — Bash-инсталляторы системных служб автоматизации на "железо" хоста.
* `logs-uploads` — единый системный лог работы фоновых задач.
