# Проект: FManager 🚀

### Имитация файлового менеджера + DevOps автоматизация + Linux-администрирование

**Описание:** 
Учебный проект для практической отработки навыков DevOps и системного администрирования Linux. Представляет собой легкое клиент-серверное приложение (frontend + backend), полностью контейнеризированное с помощью Docker и автоматизированное через CI/CD конвейер.

---

## 🛠️ Технологический стек
* **Backend:** Python (FastAPI)
* **Automation & Admin:** Bash / Shell-скрипты, системный планировщик Cron
* **Containerization:** Docker / Docker Compose
* **CI/CD:** GitHub Actions (Линтинг + Автосборка + Smoke-тесты)

---

## 🚀 Быстрый запуск

Вы можете развернуть весь проект одной командой. Для этого склонируйте репозиторий и запустите Docker Compose:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd FManager
docker compose up --build -d
```

### Доступные сервисы:
* **Frontend (Интерфейс):** [http://localhost:80]
* **Backend (API):** [http://localhost:8000/]

---

## ⚙️ Настроенный CI/CD Пайплайн
При каждом `push` или `pull_request` в ветку `main` автоматически запускается GitHub Actions workflow:
1. **Linting:** Проверка стиля и качества Python-кода backend на соответствие стандарту PEP8 с помощью утилиты `flake8`.
2. **Build:** Автоматическая сборка Docker-образов для frontend и backend.
3. **Smoke-тесты:** Запуск контейнеров в окружении GitHub Actions и проверка доступности портов (`curl`) для подтверждения успешного старта сервисов.

---

## 🐧 Автономная Linux-часть (Локальные скрипты)
В папке `scripts/` развернута независимая система обслуживания сервера, работающая через `cron`:
* **`backup`** — ежечасное создание сжатых архивов (`tar.gz`) папки хранения файлов `uploads/`.
* **`cleanMEM`** — автоматическая ротация бэкапов (удаление архивов старше 7 дней через утилиту `find`).
* **`status`** — скрипт мониторинга занятого места файлами проекта и общего состояния жесткого диска (`du` / `df`).
* **`logs-uploads`** — единый системный лог работы фоновых задач.
